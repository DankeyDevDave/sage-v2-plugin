- [ ] All bank statements ingested and classified

## Generate Pack

### Via API
```bash
curl -s http://localhost:49000/api/handover/ | python3 -m json.tool
```

### Via Pack Builder
```python
from backend.core.handover.pack_builder import HandoverPackBuilder
from backend.core.handover.assessment_generator import AssessmentGenerator
from backend.core.database.session import get_async_session_maker
import asyncio

async def build():
    session_maker = get_async_session_maker()
    builder = HandoverPackBuilder(session_maker)
    # Inspect available methods
    print([m for m in dir(builder) if not m.startswith('_')])

asyncio.run(build())
```

## Pack Contents
1. **Trial Balance** — from Sage export (`archive/sage-exports/trial_balance_report/`)
2. **Supplier Reconciliations** — matched vs unmatched per supplier
3. **Bank Reconciliations** — statement vs Sage bank account
4. **3-Way Matching Reports** — PO ↔ Invoice ↔ Payment discrepancies
5. **VAT Return** — verified against GL detail
6. **Supporting Documents** — invoices, statements, bank docs
7. **Assessment Report** — generated by `assessment_generator.py`

## Key Files
- `backend/core/handover/pack_builder.py` — pack assembly
- `backend/core/handover/assessment_generator.py` — assessment reports
- `backend/core/handover/assessment_models.py` — assessment data models
